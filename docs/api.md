# API Reference

## Base URL
`/api/v1`

## Endpoints
- `GET /health` - Health status
- `POST /auth/register` - Register a new user
- `POST /auth/login` - Login and receive JWT
- `POST /scanners/website` - Scan a website URL
- `POST /scanners/qr` - Scan a QR code
- `POST /scanners/upi` - Scan a UPI ID
- `GET /history` - Get user scan history
